# ⚖️ BMI Calculator

An interactive and responsive Body Mass Index (BMI) calculator web application. Users can adjust their weight and height using smooth range sliders to instantly calculate their BMI score and category with dynamic color coding.

## 🚀 Features
* Real-time calculation of BMI based on weight and height inputs[cite: 14].
* Interactive range sliders with live value updates (`kg` and `cm`)[cite: 13, 14].
* Dynamic category evaluation (Underweight, Normal weight, Overweight, Obese) with color-coded results[cite: 14].
* Clean card-style UI with a vibrant green gradient background[cite: 15].

## 🛠 Technologies Used
* **HTML5** (Structure, semantic tags, slider inputs)[cite: 13]
* **CSS3** (Linear gradients, custom range thumb styling, absolute centering)[cite: 15]
* **JavaScript** (Math formulas, DOM manipulation, conditional styling)[cite: 14]

## 💻 How to Run
1. Clone or download this repository.
2. Open `index.html` in any web browser[cite: 13].

# ⚖️ Калькулятор ИМТ (BMI Calculator)

Интерактивное и адаптивное веб-приложение для расчета индекса массы тела (ИМТ). Пользователи могут настраивать вес и рост с помощью удобных ползунков, чтобы мгновенно рассчитывать показатель ИМТ и определять категорию веса с динамической цветовой индикацией.

## 🚀 Особенности
* Расчет ИМТ в реальном времени на основе введенных параметров веса и роста[cite: 14].
* Интерактивные ползунки с живым обновлением значений (`кг` и `см`)[cite: 13, 14].
* Определение категории (недостаточный вес, норма, избыточный вес, ожирение) с изменением цвета текста результатов[cite: 14].
* Аккуратный интерфейс карточки на красивом зеленом градиентном фоне[cite: 15].

## 🛠 Используемые технологии
* **HTML5** (структура, теги, элементы range)[cite: 13]
* **CSS3** (линейные градиенты, кастомные ползунки, центрирование)[cite: 15]
* **JavaScript** (математические расчеты, работа с DOM, условные стили)[cite: 14]

## 💻 How to Run / Как запустить
1. Клонируйте или скачайте этот репозиторий.
2. Откройте файл `index.html` в любом веб-браузере[cite: 13].
